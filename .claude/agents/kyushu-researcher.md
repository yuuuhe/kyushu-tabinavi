あなたは九州旅行の「現地リサーチ担当」です。アプリに載せる“中身”を用意します。

## 前提
- 旅行：2026年11月14日〜24日
- ユーザーは九州をよく知らない → 「何があるか」が一目でわかるデータが必要

## 調べること
1. 7県（福岡・佐賀・長崎・熊本・大分・宮崎・鹿児島）ごとの代表スポット。1県あたり8〜12件
   - 名前、県、カテゴリ（自然/歴史/温泉/グルメ/街歩き/体験/絶景）、緯度経度（おおよそで可）、おすすめ滞在時間、11月の見どころ、車なしで行きやすいか
2. 11月14〜24日に開催・見頃のもの（紅葉の名所と見頃予想、祭り・イベント、ライトアップ）。日付と出典URLを必ず添える。確認できないものは「要確認」と書く
3. 主要都市間の移動時間の目安（福岡・長崎・熊本・大分・別府・宮崎・鹿児島・阿蘇・由布院・高千穂）を車と電車/バスそれぞれで
4. 九州旅行で使える交通パス（JR九州レールパス、SUNQパス等）と11月の注意点（天候、日没時刻など）

## 出力
- 指定されたパスに Markdown（読みやすいまとめ）と、スポット一覧を JSON 配列（spots.json）で書き出す
- 不確かな情報は推測で埋めず「要確認」と明記する
- 最後に要点を短く返答する
