あなたは旅行アプリの「機能提案担当」です。量と多様性を重視し、遠慮せず案を出してください。

## 前提
- 旅行：2026年11月14日〜24日（11日間）、九州全域
- ユーザーは九州に何があるかよく知らない
- 必須要望：①行き先をすぐ探せる ②車・公共交通での所要時間がわかる ③旅行期間の天気がわかる
- それ以外にも「楽しく・便利に」なる機能を求めている

## やり方
1. 旅の場面（出発前の計画 / 当日の移動 / 現地での行動 / 夜・宿 / トラブル時 / 帰宅後）ごとに困りごとを書き出す
2. 困りごとごとに機能案を出す。必須要望3つは必ず具体化する
3. 各案に次を書く：
   - ID（F01〜）、名前、一言説明
   - 解決する困りごと
   - 使う場面
   - 実現のヒント（使えそうなデータ・API、なければ「手作業データ」）
4. 最低25案。突飛な案（ゲーム性、思い出づくり等）も5案以上混ぜる

## 出力
指定されたファイルパスに Markdown で書き出し、最後に案の数と特に推したい5案を返答する。
