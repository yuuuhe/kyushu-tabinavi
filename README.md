# 九州たびナビ（2026/11/14〜24）

九州旅行用のスマホ向けウェブアプリ。ビルド不要・APIキー不要・費用ゼロ。計画は [docs/PLAN.md](docs/PLAN.md)。

## できること
- **探す**：69スポットを地図／リストで。県・カテゴリ・タグ（絶景・紅葉・雨OK・夜・車なしOK・★）で絞り込み、文字検索、絶景優先のおすすめ順、現在地から近い順
- **スポット詳細**：11月の見どころ、要確認バッジ、出典、Googleマップ（車／電車・バス）、★行きたい、日付に追加
- **移動**：2地点の車の時間（渋滞なし〜×1.3）と電車・バスの目安（主要駅経由・乗換つき）、Googleマップの経路リンク
- **天気**：11/14〜24 の11日分（Open-Meteo）。11/18 までは気象庁の週間予報と信頼度、全日に平年値と日の入り
- **旅程**：日ごとの拠点・スポット・メモ。スポット間の車の時間を表示。書き出し／読み込み
- **オフライン**：一度開けば圏外でも本体・データ・最後の天気が見られる（地図は除く）

## パソコンで動かす
```bash
python -m http.server 8765
```
→ http://localhost:8765

## スマホで使う（GitHub Pages）
1. GitHub で新しいリポジトリを作り、このフォルダを push
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存
3. 表示された URL をスマホで開き、「ホーム画面に追加」
   - iPhone：Safari の共有ボタン →「ホーム画面に追加」
   - Android：Chrome のメニュー →「ホーム画面に追加」／「アプリをインストール」
4. Wi-Fi のあるうちに一度開き、各タブを表示しておく（オフライン用に保存される）

公開リポジトリは誰でも見られます。旅程は端末の中だけに保存され、リポジトリには入りません。

## データの作り直し
```bash
python scripts/prepare_data.py
```
タグ・車の所要時間（OSRM）・平年値（Open-Meteo）を作り直します。データを変えたら `sw.js` の `CACHE` の版（`tabinavi-v1`）を上げてください。
