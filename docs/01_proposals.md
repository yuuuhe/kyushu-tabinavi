# 九州旅行アプリ 機能提案（発散版）

- 作成日：2026-11-11
- 対象の旅行：2026年11月14日（土）〜24日（火）の11日間、九州全域（福岡・佐賀・長崎・熊本・大分・宮崎・鹿児島）
- 前提：ユーザーは九州に何があるかよく知らない
- 必須要望：①行き先をすぐ探せる ②車・公共交通での所要時間がわかる ③旅行期間の天気がわかる
- 方針：量と多様性を重視。実装の難しさはここでは気にせず出し切る（絞り込みは次の工程で行う）

---

## 1. 場面ごとの困りごと

### A. 出発前の計画
- A1. 九州に何があるか知らない。県ごとの特徴もわからない
- A2. 11日間をどう割り振ればよいかわからない（どの県に何日いるか）
- A3. 行きたい場所どうしがどのくらい離れているかわからない（九州は広い）
- A4. 11月中旬〜下旬の天気・気温がわからない。服装の見当がつかない
- A5. 紅葉・祭り・イベントなど「この時期だけ」のものを知らない
- A6. 車にするか、電車・バスにするか決められない
- A7. 宿をどこに取ればよいかわからない（拠点をどこにするか）
- A8. 予算の見当がつかない

### B. 当日の移動
- B1. 次の目的地まで車で何分、電車・バスで何分かすぐ知りたい
- B2. 地方のローカル線・バスは本数が少なく、乗り逃すと詰む
- B3. 運転中に操作できない。休憩場所（道の駅・SA）がわからない
- B4. 離島・フェリー（五島・屋久島・天草など）の時刻や欠航がわからない
- B5. 阿蘇・霧島など火山の規制、道路の通行止めを知らない

### C. 現地での行動
- C1. 「今いる場所の近くで何ができるか」がわからない
- C2. 雨の日に行ける場所がすぐ思いつかない
- C3. 何を食べればよいか、ご当地グルメを知らない
- C4. 営業時間・定休日を調べるのが面倒
- C5. 温泉が多すぎて選べない
- C6. 見どころを見ても背景（歴史・由来）がわからず楽しみが半減する

### D. 夜・宿
- D1. 翌日の予定を立て直したい（天気が変わった、疲れた等）
- D2. 夕食・夜の過ごし方を探したい
- D3. 今日どこに行ったか、何を使ったかを整理したい
- D4. コインランドリーを探したい（11日間の長旅）

### E. トラブル時
- E1. 電車の遅延・運休、フェリーの欠航
- E2. 体調不良・ケガ。近くの病院がわからない
- E3. 忘れ物・紛失、車の故障・ガス欠
- E4. 地震・火山の噴火・大雨などの災害

### F. 帰宅後
- F1. 写真が散らばって、どこで撮ったかわからなくなる
- F2. 旅の思い出を人に見せたい・残したい
- F3. お金の精算（同行者がいる場合）
- F4. 「また行きたい」場所を次に生かしたい

## 2. 機能案一覧

凡例：★＝必須要望の具体化（①探す ②所要時間 ③天気）／🎲＝突飛な案（ゲーム性・思い出づくり等）

### 必須要望① 行き先をすぐ探せる

#### F01 ★① 九州まるわかりマップ
- 一言説明：九州全体の地図に「定番スポット」をアイコンで並べ、タップで写真・説明・所要滞在時間が出る
- 解決する困りごと：A1（何があるかわからない）
- 使う場面：出発前の計画、現地
- 実現のヒント：地図は Leaflet＋OpenStreetMap、または Google Maps JavaScript API。スポット情報は手作業データ（各県で10〜20件程度を JSON で用意）。補助に Google Places API

#### F02 ★① 気分で探す（タグ検索）
- 一言説明：「絶景」「温泉」「グルメ」「歴史」「雨でもOK」「子どもと」などのタグを押すだけで候補が絞れる
- 解決する困りごと：A1、C2
- 使う場面：出発前、現地
- 実現のヒント：手作業データにタグを付与してクライアント側でフィルタ

#### F03 ★① 「今ここから近い順」リスト
- 一言説明：現在地から近い順・行ける順にスポットを並べる
- 解決する困りごと：C1（近くで何ができるかわからない）
- 使う場面：現地での行動
- 実現のヒント：ブラウザの Geolocation API＋スポット座標で距離計算（ハバーサイン式）

#### F04 ★① 県別ガイドカード
- 一言説明：7県それぞれを「一言で言うと」「外せない3つ」「名物」「移動のコツ」の1枚カードで紹介
- 解決する困りごと：A1、A2
- 使う場面：出発前
- 実現のヒント：手作業データ

#### F05 ★① 11月の旬スポット特集
- 一言説明：11月中旬〜下旬に見頃・開催のもの（紅葉、秋祭り、イルミネーション、旬の食材）だけを集めた特集
- 解決する困りごと：A5（この時期だけのものを知らない）
- 使う場面：出発前
- 実現のヒント：手作業データ（各県観光協会のイベント情報を参照）。紅葉見頃は各種紅葉情報サイトを参照

#### F06 ★① ひとことで探す（自然文検索）
- 一言説明：「熊本で雨でも楽しめる場所」「海の見えるカフェ」など文章で聞くと候補が出る
- 解決する困りごと：A1、C1、C2
- 使う場面：いつでも
- 実現のヒント：Claude API などの LLM に手作業データを渡して絞り込み。または Google Places API Text Search

### 必須要望② 車・公共交通での所要時間

#### F07 ★② 2地点の所要時間くらべ
- 一言説明：出発地と目的地を選ぶと「車で◯分／電車・バスで◯分（乗換◯回）」を並べて表示
- 解決する困りごと：B1、A6
- 使う場面：計画、当日の移動
- 実現のヒント：Google Maps Directions API / Routes API（driving・transit）。公共交通は Google の transit か、NAVITIME API・駅すぱあと API

#### F08 ★② 距離感ヒートマップ（ここから◯時間圏）
- 一言説明：拠点を選ぶと、車で1時間・2時間・3時間で行ける範囲を地図に色で塗る
- 解決する困りごと：A3（九州の広さがわからない）、A7（拠点選び）
- 使う場面：出発前の計画
- 実現のヒント：Mapbox Isochrone API、OpenRouteService の isochrones（無料枠あり）

#### F09 ★② 1日のルート自動並べ替え
- 一言説明：その日行きたい場所を選ぶと、移動時間が最短になる順番に並べ、合計の移動時間・滞在時間を表示
- 解決する困りごと：B1、A2
- 使う場面：計画、夜に翌日の準備
- 実現のヒント：Google Routes API の waypoint 最適化、または距離行列＋簡易な巡回計算

#### F10 ★② 終電・最終バス アラート
- 一言説明：今いる場所から宿に公共交通で帰れる最終時刻を常に表示し、近づいたら通知
- 解決する困りごと：B2（本数が少なく乗り逃すと詰む）
- 使う場面：当日の移動、夜
- 実現のヒント：NAVITIME / 駅すぱあと API、各社の GTFS データ（九州のバス会社の一部は GTFS-JP を公開）。通知は Web Push

#### F11 ★② 車 vs 公共交通 判定
- 一言説明：旅程全体を見て「この区間はレンタカー、この区間は新幹線が楽」と提案し、時間と費用の目安を出す
- 解決する困りごと：A6（どちらにするか決められない）
- 使う場面：出発前
- 実現のヒント：F07 の結果を区間ごとに比較。費用はガソリン代の概算＋高速料金（NEXCO 西日本の料金検索参照）、運賃は経路検索 API

#### F12 ★② フェリー・離島ナビ
- 一言説明：五島・壱岐・対馬・屋久島・天草などへの船の時刻、所要時間、運航状況へのリンクをまとめる
- 解決する困りごと：B4
- 使う場面：計画、当日
- 実現のヒント：手作業データ（各航路会社の時刻表）。運航状況は各社サイトへのリンク

### 必須要望③ 旅行期間の天気

#### F13 ★③ 11日間お天気カレンダー
- 一言説明：11/14〜24 を1枚に並べ、日ごとに「その日に泊まる場所」の天気・最高/最低気温・降水確率を表示
- 解決する困りごと：A4、D1
- 使う場面：出発前、毎晩
- 実現のヒント：Open-Meteo API（無料・キー不要、16日先まで）、気象庁の天気予報 JSON（府県単位・週間予報）。予報が届かない日は平年値を表示

#### F14 ★③ スポット別ピンポイント天気
- 一言説明：各スポットの詳細画面に、訪問予定日のその地点の天気を表示（山の上と街中は違う）
- 解決する困りごと：A4、C2
- 使う場面：計画、現地
- 実現のヒント：Open-Meteo（緯度経度で取得、標高補正あり）

#### F15 ★③ 雨プラン自動差し替え
- 一言説明：予定日の降水確率が高いと「代わりにこの屋内スポットはどう？」と近くの雨でもOKな場所を提案
- 解決する困りごと：C2、D1
- 使う場面：前日の夜、当日朝
- 実現のヒント：F13 の天気＋F02 の「雨でもOK」タグ

#### F16 ★③ 服装アドバイス
- 一言説明：その日の最高/最低気温と行き先の標高から「薄手のダウンがあると安心」などを表示
- 解決する困りごと：A4（服装の見当がつかない）
- 使う場面：前日の夜、朝
- 実現のヒント：Open-Meteo の気温＋簡単なルール（例：最低10℃未満なら上着）

#### F17 ★③ 絶景コンディション予報
- 一言説明：雲海（高千穂の国見ヶ丘・阿蘇）、夕日、星空などが見えやすい日を天気から予想
- 解決する困りごと：A5、C1
- 使う場面：計画
- 実現のヒント：Open-Meteo の雲量・湿度・風速・気温差から簡易ルールで判定。日の出・日の入りは Open-Meteo や sunrise-sunset API

### 出発前の計画

#### F18 11日間の旅程ボード
- 一言説明：日付ごとの列にスポットをドラッグで置ける旅程表。移動時間・天気も自動で表示
- 解決する困りごと：A2
- 使う場面：出発前、夜
- 実現のヒント：自作UI（ブラウザの localStorage に保存）。F07・F13 と連携

#### F19 おまかせモデルコース
- 一言説明：「九州一周11日間」「北部じっくり」「温泉三昧」など完成済みのコースを選んでから自分用に直せる
- 解決する困りごと：A1、A2（ゼロから考えるのが大変）
- 使う場面：出発前
- 実現のヒント：手作業データ。LLM で好みに合わせて調整する案も

#### F20 拠点（宿エリア）おすすめ
- 一言説明：行きたい場所を選ぶと、移動が少なくて済む宿泊エリア（例：福岡市・熊本市・別府）を提案
- 解決する困りごと：A7
- 使う場面：出発前
- 実現のヒント：行き先の重心＋F08 の到達圏。宿検索は楽天トラベル API・じゃらん Web サービスへのリンク

#### F21 予算ざっくり計算
- 一言説明：宿・交通・食事・入場料を日ごとに見積もり、合計と1日あたりを表示
- 解決する困りごと：A8
- 使う場面：出発前
- 実現のヒント：入場料・運賃は手作業データ／経路 API の運賃、食事は固定の目安値

#### F22 持ち物チェックリスト
- 一言説明：天気・行き先（温泉、山、離島）に合わせて持ち物リストを自動で作る
- 解決する困りごと：A4
- 使う場面：出発前
- 実現のヒント：手作業ルール＋F13 の天気

### 当日の移動

#### F23 ドライブモード（大きいボタン・音声）
- 一言説明：運転中は文字を大きく、操作を最小限に。「次の目的地まであと◯分」を音声で
- 解決する困りごと：B3
- 使う場面：車での移動
- 実現のヒント：Web Speech API（音声合成）。ナビ本体は Google マップアプリへ連携（URL スキーム）

#### F24 休憩スポット提案
- 一言説明：運転2時間ごとに、ルート沿いの道の駅・SA/PA・景色のよい休憩地を提案
- 解決する困りごと：B3
- 使う場面：車での移動
- 実現のヒント：国土交通省「道の駅」データ（国土数値情報）、Google Places API

#### F25 通行規制・火山情報チェック
- 一言説明：阿蘇・霧島・桜島など火山の規制レベル、道路の通行止めを行き先と照らして警告
- 解決する困りごと：B5、E4
- 使う場面：前日、当日
- 実現のヒント：気象庁の噴火警報・噴火警戒レベル（防災情報 XML）、日本道路交通情報センター（JARTIC）、各県の道路規制情報へのリンク

### 現地での行動

#### F26 ご当地グルメ図鑑
- 一言説明：県・地域ごとの名物（もつ鍋、ちゃんぽん、馬刺し、とり天、チキン南蛮、黒豚など）と食べられる店
- 解決する困りごと：C3
- 使う場面：現地、昼・夜
- 実現のヒント：グルメ名は手作業データ、店はホットペッパーグルメ API・Google Places API

#### F27 営業中フィルタ
- 一言説明：「今開いている」「この後◯時まで開いている」場所だけを表示。定休日も警告
- 解決する困りごと：C4
- 使う場面：現地
- 実現のヒント：Google Places API の opening_hours

#### F28 温泉セレクター
- 一言説明：泉質・日帰り可否・料金・貸切風呂・景色で温泉を絞り込み。別府・由布院・黒川・指宿など比較
- 解決する困りごと：C5
- 使う場面：計画、現地
- 実現のヒント：手作業データ（主要温泉地30件程度）

#### F29 スポット音声ガイド
- 一言説明：スポットに着くと、由来や見どころを1〜2分で読み上げ
- 解決する困りごと：C6
- 使う場面：現地
- 実現のヒント：解説文は手作業データまたは LLM で作成、Web Speech API で読み上げ。Geolocation でジオフェンス

#### F30 混雑予想
- 一言説明：人気スポットの「空いている時間帯」を表示（週末と平日の違いなど）
- 解決する困りごと：C1、C4
- 使う場面：計画、現地
- 実現のヒント：Google の「混雑する時間帯」は公式 API 未提供のため、手作業データ（曜日×時間の目安）または BestTime.app API

### 夜・宿

#### F31 明日の作戦会議画面
- 一言説明：夜に開くと、明日の天気・予定・移動時間・最終便・服装を1画面にまとめて表示し、変更もできる
- 解決する困りごと：D1
- 使う場面：夜・宿
- 実現のヒント：F13・F09・F10・F16 をまとめるダッシュボード

#### F32 夜の楽しみ探し
- 一言説明：屋台（福岡・中洲）、夜景（稲佐山・皿倉山）、星空、ライトアップなど夜に行ける場所だけを表示
- 解決する困りごと：D2
- 使う場面：夜
- 実現のヒント：手作業データ＋F27 の営業中フィルタ

#### F33 旅の家計簿
- 一言説明：使ったお金をワンタップ記録。カテゴリ別・日別に集計。同行者との割り勘計算も
- 解決する困りごと：D3、F3
- 使う場面：夜、帰宅後
- 実現のヒント：自作（localStorage）。割り勘は簡単な精算アルゴリズム

#### F34 生活インフラ検索
- 一言説明：コインランドリー、ドラッグストア、コンビニ、ガソリンスタンドを近い順に
- 解決する困りごと：D4、E3
- 使う場面：夜、移動中
- 実現のヒント：Google Places API、OpenStreetMap（Overpass API）

### トラブル時

#### F35 運休・遅延ウォッチ
- 一言説明：旅程に入っている路線（JR九州・西鉄・フェリー）の運行情報をまとめて表示し、乱れがあれば代わりのルートを提案
- 解決する困りごと：E1
- 使う場面：当日
- 実現のヒント：JR九州の列車運行情報ページへのリンク／ODPT（公共交通オープンデータ）で取得できる範囲、代替ルートは F07

#### F36 困ったときボタン
- 一言説明：「体調不良」「ケガ」「紛失」「車の故障」「災害」を選ぶと、近くの病院・交番・連絡先・やることリストが出る
- 解決する困りごと：E2、E3、E4
- 使う場面：トラブル時
- 実現のヒント：手作業データ（#7119 などの救急相談、JAF #8139、レンタカー会社連絡先）、病院・交番は Google Places API／OSM

#### F37 防災アラート
- 一言説明：滞在地の地震・大雨・噴火の警報を通知し、近くの避難所を表示
- 解決する困りごと：E4
- 使う場面：いつでも
- 実現のヒント：気象庁 防災情報 XML、国土地理院の指定緊急避難場所データ

#### F38 オフライン保存
- 一言説明：旅程・地図・連絡先を端末に保存し、山間部や離島で電波がなくても見られる
- 解決する困りごと：B4、E 全般（電波が弱い場所での不安）
- 使う場面：移動中、離島、山
- 実現のヒント：PWA（Service Worker でキャッシュ）、地図タイルの事前ダウンロード

### 帰宅後

#### F39 旅の自動アルバム
- 一言説明：写真の撮影日時・位置情報から、日ごと・スポットごとに自動でアルバムを作る
- 解決する困りごと：F1
- 使う場面：帰宅後（旅行中も随時）
- 実現のヒント：写真の EXIF 情報を読み取る（exifr などのライブラリ）、地図上にプロット

#### F40 「また行きたい」リスト
- 一言説明：行けなかった場所・もう一度行きたい場所をメモし、次の旅行計画に引き継ぐ
- 解決する困りごと：F4
- 使う場面：旅行中、帰宅後
- 実現のヒント：自作（localStorage／エクスポート）

### 🎲 突飛な案（ゲーム性・思い出づくり）

#### F41 🎲 九州スタンプラリー（7県制覇バッジ）
- 一言説明：スポットに行くと位置情報でスタンプ獲得。7県制覇、温泉10湯、ご当地グルメ5種などでバッジ
- 解決する困りごと：旅の動機づけ、F2（思い出を残したい）
- 使う場面：旅行中ずっと

## 4. 特に推したい5案

1. **F01 九州まるわかりマップ**（必須①）
   九州をよく知らないユーザーにとって、まず「何があるか」を地図で一望できることが全ての出発点。F02 のタグ検索と組み合わせると強い。
2. **F07 2地点の所要時間くらべ**（必須②）
   車と公共交通を並べて比べられるのが要望そのもの。F09（ルート並べ替え）・F11（車 vs 公共交通判定）の土台にもなる。
3. **F13 11日間お天気カレンダー**（必須③）
   Open-Meteo なら無料・キー不要で16日先まで取れ、出発3日前の今から旅程全体をほぼカバーできる。宿泊地と連動させると実用性が高い。
4. **F31 明日の作戦会議画面**
   天気・移動時間・最終便・服装を夜に1画面で確認でき、必須3要望を「毎日使う形」にまとめる。11日間の長旅で最も使われる画面になりそう。
5. **F41 九州スタンプラリー（7県制覇バッジ）**🎲
   位置情報だけで作れて、旅全体を通して楽しさを足せる。帰宅後の F50「旅の通信簿」へもつながる。
